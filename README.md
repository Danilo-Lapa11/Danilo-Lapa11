I am a Data Scientist and Machine Learning Engineer with professional experience developing analytical and AI solutions for real-world problems.

My work includes Machine Learning, real-time data analysis, climate risk classification, traffic anomaly detection, LLM-based applications, API development, and analytical platforms.

I also have research experience applying Machine Learning to public health, spatiotemporal prediction, NLP, and speech recognition.
